# めぐりまち（地域創生ハッカソン デモ）

地元の人が投稿した「穴場スポット」を、AI（Claude）が旅行者好みの旅プランに組み立てます。訪れた人や地元の人が残した「足跡」は地図上に色分けして表示されます。

## 主な機能

- **穴場を探す**：地元の人が投稿したスポットの一覧。キーワード・エリア・カテゴリで絞り込み、「穴場度」順などで並べ替えられます
- **穴場を投稿**：地元の人が地図をタップして場所を選び、楽しみ方のコツと一緒に投稿します
- **足跡マップ**：地元の足跡（緑）と旅人の足跡（オレンジ）の表示、にぎわいのオーラ、最新の足跡フィード、穴場ランキング
- **AI旅プラン**：エリア・日程・興味・同行者・ペース・移動手段をもとに、Claude が旅程とルート地図を作ります

穴場度は、地元の人の足跡が多く、旅人の足跡が少ないほど高くなる指標です（`frontend/src/utils/spotStats.ts`）。

## 起動方法

ターミナルを2つ使います。

```bash
# 1. AI 旅プラン API サーバー（ポート 8787）
cd server
npm install
cp .env.example .env   # ANTHROPIC_API_KEY を記入
npm run dev

# 2. フロントエンド（http://localhost:5173）
cd frontend
npm install
npm run dev
```

API キーがない、またはサーバーが起動していない場合、AI旅プランは自動的に「デモモード」（穴場度をもとにした簡易生成）に切り替わります。

投稿したスポットや足跡はブラウザの localStorage に保存されます。初期状態に戻すには、開発者ツールで `meguri:spots:v1` を削除してください。
